# Predictable Health Indicator - Estimates an opponent's approximate health

This mod estimates an opponent's approximate health by accounting for healing, armor, and the use of healing potions. Unlike other health indicators, it does not rely on scoreboard data or external data trackers. Please note that the mod may occasionally provide inaccurate calculations, as it cannot determine an opponent's exact health.

**DISCLAIMER ‼️**
Do not use this mod on FT (Fantasy/RPG-style servers) for now; there are too many attributes derived from talismans and potions that still need to be accounted for and tested. I plan to adapt it for FT in the future. For the time being, the mod is intended exclusively for SMP servers that feature "anti-health-indicator" mechanics (such as those found on the Blood Astrum server).
